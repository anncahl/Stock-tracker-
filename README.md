# Budget Tracker
## Description
This project is a visual identity design for a budget tracker application built using HTML and CSS
## Features Implemented
### 1 Color Palette
-Added CSS custom variables for background,text,accent and header colours.
### 2 Typography
-Connected goggle fonts:Montserrat for headings and Roboto for body text.
### 3 Table and Form Styling
-Form inputs have padding,rounded borders and styled buttons
-Expense table features custom header,row,hover effects and alternating row colours
### 4 CSS Box Model
-Section containers using padding,margins,borders and border radius to create card-style layout
## Files Included
-'index-html'-web page structure
-'styles'-application Styling
-'README.md'-project documentation
